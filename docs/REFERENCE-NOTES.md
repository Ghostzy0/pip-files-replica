# Reference notes

The primary behavior reference is Hazel 6.1.2. This independent app uses published Noodlesoft documentation to identify workflows; no source, screenshots, icons, media or UI copy from Hazel is included.

The source export also retains original MIT-licensed Pip-edition UI and icon-generator components for shared build/test reuse. The `replica` package selects a neutral folder icon and Replica view; it does not display the Pip theme or character. No Pip screenshots or private/reference images are included.

## Documented workflow

The official manual describes selecting a folder, creating and naming a rule, selecting condition grouping, editing conditions, ordering actions, choosing destinations, and validating a Save. It documents a single-file preview that reports condition matches without running actions and a separate rule-status table. These are documentation statements, not claims that those screens were directly observed in Hazel during the current app session.
