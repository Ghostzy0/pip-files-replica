# Roadmap

Every item below is proposed work, not an implemented feature or promise.

- Observe and document the supported Hazel 6.1.2 rule workspace with synthetic folders, if the native reference remains available under the approved terms.
- Compare one same-input rule/editor/preview/status path and record the differences.
- Complete synthetic native keyboard, accessibility, save-validation and recovery checks for a clean `Files Replica` package.
- Revisit only the missing workflow gaps that have clear documented behavior and safe, testable implementation boundaries.
- Consider an experimental source release after clean export, tests, independent review and CI pass; a binary release additionally needs exact-build native acceptance and checksum verification.

No feature, release date, compatibility claim or parity milestone is guaranteed by this list.
