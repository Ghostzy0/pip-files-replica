# Files Replica

This repository is being prepared as the separate home for an experimental neutral macOS folder-automation source profile. The proposed app is an original, manual-informed workflow implementation; it is not affiliated with Noodlesoft and does not claim complete Hazel parity or verified 1:1 recreation.

No app bundle is published here. The initial app-source pull request is being prepared for review and will provide the exact build, test, licence, provenance and acceptance information before this repository contains runnable source.
